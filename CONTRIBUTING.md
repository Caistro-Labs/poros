# Contributing to Poros

Thanks for wanting to help. We build Poros ourselves and don't merge pull requests from outside
the team, but there is a lot you can do:

- **Report a bug** with the [bug form](https://github.com/Caistro-Labs/poros/issues/new/choose):
  the command, the model, the output of `poros machine` and `poros check <model>`, and the full
  output.
- **Tell us what fit** on your machine, or didn't, with the hardware report form.
- **Ask for a model family** with an architecture request. If you ran `poros prove <model>
  --unvalidated`, attach the pack it wrote.
- **Share an idea** in [Discussions](https://github.com/Caistro-Labs/poros/discussions).

If we build something from your issue or idea, we credit you in the changelog by your GitHub
handle, if you're happy with that.

Found a security problem? Please don't open an issue: see [SECURITY.md](SECURITY.md).
